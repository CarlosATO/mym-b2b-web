# Plan Maestro: MYM Web B2B

## Objetivo del Proyecto
Desarrollar una nueva plataforma web B2B moderna y eficiente para MYM Distribuidora, independiente de la actual infraestructura en WordPress/WooCommerce. El foco principal es ofrecer una experiencia optimizada para clientes comerciales (B2B), con catálogos rápidos, y un panel de administración avanzado.

## Puntos Clave
1. **No tocar la web actual**: La infraestructura actual en WordPress/WooCommerce permanecerá intacta y operando normalmente. Esta nueva plataforma existirá en paralelo y eventualmente la reemplazará en el segmento B2B.
2. **Catálogo Público**: Los visitantes no autenticados podrán ver el catálogo completo de productos, pero **NO** tendrán acceso a los precios.
3. **Acceso a Clientes**: Los clientes comerciales, una vez autenticados y aprobados, podrán ver los precios especiales para ellos y la disponibilidad general de los productos.
4. **Gestión Administrativa**: Un panel admin moderno permitirá al equipo gestionar el contenido web (banners, imágenes, visibilidad, etc.).
5. **Bsale como Fuente Oficial**: Bsale será la fuente de la verdad para precios y stock.
6. **Pagos Online**: La implementación de pasarelas de pago no es parte del MVP o Fase 0, se evaluará en etapas posteriores.
